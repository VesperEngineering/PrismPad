# PrismPad v0.1.1

PrismPad is a lightweight, local-only desktop code and text editor for Windows 10/11 x64 and Ubuntu 24.04+ x64.

## Highlights

- Patched the Markdown preview sanitizer dependency used in production builds.
- A sleek, colorful editor with connected boxed tabs and no IDE overhead.
- “Hello! What will you code in today?” startup chooser with 20 language choices.
- Extension-aware syntax for Python, Markdown, YAML, JSON, JavaScript, TypeScript, JSX, TSX, HTML, CSS, Shell, PowerShell, Rust, C, C++, Java, SQL, TOML, XML, and plain text.
- Multiple documents, safe Save and Save As flows, find/replace, folding, multiple selections, whitespace and indentation controls, themes, and Markdown preview.
- Local-only operation with no accounts, telemetry, cloud sync, or network service.

PrismPad v0.1.1 is unsigned. Windows may show a Microsoft Defender SmartScreen warning when the installer is opened. Verify that the download comes from the official VesperEngineering/PrismPad GitHub release before installing it.
